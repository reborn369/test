# Быстрый старт

MINTER — программа для массового минта NFT с большого количества кошельков.

Выберите один из двух вариантов. Оба рабочие, разница только в том, где
программа крутится.

|  | Вариант А: на своём компьютере | Вариант Б: на сервере |
|---|---|---|
| Что нужно | ничего | арендованный VPS (~5$/мес) |
| Сложность | скачал и запустил | 10 минут настройки |
| Компьютер во время минта | должен быть включён | можно выключить |
| Скорость | как повезёт с интернетом | быстрее, сервер рядом с сетью |

**Если сомневаетесь — начните с варианта А.** Переехать на сервер можно позже.

---

# Вариант А — на своём компьютере (Windows)

### 1. Скачать

Откройте [страницу релизов](https://github.com/MaxBetov-pdd/Minter-rs-v2/releases/latest)
и скачайте файл, который заканчивается на **`windows-x64.zip`**.

### 2. Распаковать

Правой кнопкой по скачанному файлу → «Извлечь всё». Положите куда удобно,
например в `C:\Minter\`.

### 3. Запустить

Двойной клик по **`minter-desktop.exe`**.

> Windows покажет синее окно «Система защитила ваш компьютер».
> Это нормально — программа не подписана платным сертификатом.
> Нажмите **«Подробнее»** → **«Выполнить в любом случае»**.

Готово. Переходите к разделу «Первый запуск» внизу.

# Вариант Б — на сервере

Понадобится VPS с Linux. Подойдёт Ubuntu, Debian, Fedora, RHEL, Rocky, Alma
или Arch — **команда ниже одна и та же для всех**, скрипт сам определит систему
и поставит что нужно.

Графическая оболочка на сервере **не нужна** — только терминал.

> Не подойдут Ubuntu 20.04 и Debian 11: они слишком старые, нужной библиотеки
> там просто нет. Установщик скажет об этом сразу и ничего не сломает.
> Берите Ubuntu 22.04 или новее.

## Часть 1: настроить сервер

### 1. Зайти на сервер

Откройте на своём компьютере **PowerShell** (кнопка «Пуск» → наберите
`powershell`) и введите, подставив адрес своего сервера:

```
ssh root@ВАШ_IP_СЕРВЕРА
```

Введите пароль, который прислал хостинг. Пароль при вводе не отображается —
это нормально, печатайте вслепую и жмите Enter.

### 2. Установить

Скопируйте эту строку целиком и вставьте в окно (правой кнопкой мыши):

```
curl -fsSL https://raw.githubusercontent.com/MaxBetov-pdd/Minter-rs-v2/main/deploy/linux/install.sh | sudo bash
```

Установщик спросит **пароль для VNC** — придумайте любой от 8 символов и
запишите его. Дальше всё сделает сам, это займёт пару минут.

В конце он напечатает подсказку — там будут **адрес сервера** и **пользователь**.
Они понадобятся на следующем шаге, не закрывайте окно.

## Часть 2: подключиться со своего компьютера

### 3. Скачать коннектор

Откройте [github.com/MaxBetov-pdd/minter-connect](https://github.com/MaxBetov-pdd/minter-connect),
нажмите зелёную кнопку **Code** → **Download ZIP**. Распакуйте.

### 4. Запустить

Правой кнопкой по **`connect.ps1`** → **«Выполнить с помощью PowerShell»**.

При первом запуске он спросит:

```
  Server address (IP or hostname): вводите адрес сервера
  SSH user [root]: вводите пользователя
```

Потом один раз попросит пароль от сервера — тот самый, от хостинга. Это
последний раз, дальше вход будет автоматический.

Через несколько секунд откроется браузер с программой.

> Если Windows ругается, что скрипты запрещены — откройте PowerShell в той же
> папке и введите:
> ```
> powershell -ExecutionPolicy Bypass -File .\connect.ps1
> ```

### Каждый следующий раз

Просто двойной клик по `connect.ps1`. Браузер откроется сам за пару секунд.

Чтобы закрыть соединение: `.\connect.ps1 -Stop`

# Первый запуск

Дальше одинаково для обоих вариантов.

### 1. Придумайте пароль хранилища

Программа попросит создать пароль. Им шифруются ваши приватные ключи на диске.

**Запишите его.** Восстановить нельзя — забыли пароль, потеряли кошельки.

### 2. Добавьте кошельки

Раздел **Wallets**. Можно вставить готовые приватные ключи или нажать
«сгенерировать» и создать новые пустые.

### 3. Пополните их

Переведите на кошельки немного ETH в той сети, где будете минтить.

### 4. Настройте сеть

Раздел **RPCs**. Вставьте ключ Alchemy (бесплатный на
[alchemy.com](https://alchemy.com)) — без него будет работать медленнее.
Нажмите **Ping networks**, чтобы проверить связь.

### 5. Создайте задачу

Раздел **Tasks** → создать задачу → вставьте ссылку на коллекцию OpenSea,
укажите количество и время старта.

**Первый раз обязательно оставьте галочку Dry Run.** Программа всё подготовит,
но ничего не отправит и денег не потратит — вы увидите, что получилось бы.
Убедились, что всё верно — снимайте галочку.

# Безопасность — прочитайте, это важно

**Только одноразовые кошельки.** Никогда не заводите сюда кошелёк, где лежат
ваши основные деньги. Программа хранит ключи зашифрованными, но любой минт-бот
— это риск.

**Никому не отправляйте эти файлы:**
`keys.vault`, `config.json`, `auth_cache.bin` — в них ключи и доступы.

**Не открывайте порт 3021 в интернет.** Если кто-то посоветует «пробросить
порт наружу» — не делайте. Пароль там слабый по устройству самого протокола
(работают только первые 8 символов). Подключайтесь только через коннектор.

**Про Dry Run.** Он включён по умолчанию не просто так. Живой запуск ещё
попросит вас напечатать слово `LIVE` — это защита от случайного клика.

# Обновления

Программа раз за запуск спрашивает у GitHub, не вышла ли версия новее. Если
вышла — сверху появится полоска со ссылкой на страницу релизов. Закрыли её —
для этой версии больше не покажется.

Что при этом уходит: обычный запрос к `api.github.com`, без единого байта о
вас — ни кошельков, ни адресов, ни идентификаторов. Ничего не скачивается и не
устанавливается само, обновляетесь вы вручную. Нет интернета — проверка молча
пропускается.

# Если что-то пошло не так

**Не открывается браузер после `connect.ps1`**
Служба могла не подняться. Проверьте:
```
ssh ПОЛЬЗОВАТЕЛЬ@СЕРВЕР "systemctl status minter-vps"
```

**Чёрный экран вместо программы**
Перезапустите службу — но только если сейчас не идёт минт:
```
ssh ПОЛЬЗОВАТЕЛЬ@СЕРВЕР "sudo systemctl restart minter-vps"
```
После перезапуска пароль хранилища придётся ввести заново.

**Каждый раз спрашивает пароль**
Ключ не прижился. Сбросьте настройки и пройдите заново:
```
.\connect.ps1 -Reset
```

**Минт не прошёл**
Откройте лог задачи в программе. Там по шагам видно, что произошло: какой
RPC-узел принял транзакцию, сколько заняла отправка, и почему не получилось.
